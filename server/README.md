# Servidor WifiDoorbell

Este diretório contém o script em Python que funciona como o "Cérebro" do sistema, rodando em um servidor Linux (como um Raspberry Pi).

## Como rodar
1. Edite o arquivo `scanner.py` e coloque o MAC Address que você quer monitorar.
2. Rode o script: `python3 scanner.py`
